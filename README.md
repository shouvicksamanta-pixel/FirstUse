# RSI Divergence Indicator for TradingView

A comprehensive Pine Script v4 indicator that detects RSI divergences and provides automated trading signals with position tracking and alert capabilities.

## 📁 Project Files

- **`rsi_divergence_indicator.pine`** - Main Pine Script indicator code
- **`RSI_Divergence_Indicator_Documentation.md`** - Detailed documentation and usage guide

## 🎯 Key Features

- **Divergence Detection**: Regular & Hidden Bullish/Bearish divergences
- **Visual Signals**: Color-coded bars and labeled divergence points  
- **Alert System**: Automated BUY/SELL alerts
- **Position Tracking**: Persistent position state management
- **Customizable Parameters**: Fully configurable RSI and lookback settings

## 🚀 Quick Start

1. Copy the code from `rsi_divergence_indicator.pine`
2. Paste into TradingView Pine Editor
3. Add to chart and configure parameters
4. Set up alerts for entry/exit signals

## 📊 Visual Indicators

- **🟡 Yellow bars**: Long entry signals
- **🟣 Purple bars**: Long exit signals  
- **🔵 Blue bars**: Active long position
- **Labels**: "PD", "PRD", "ND", "NRD" mark divergences
